1. A full lesson plan from one standard

K-2 · 3-5 · 6-8 · 9-12

Supply standard text and lesson duration to create a plan for review.

The prompt

You are an experienced [GRADE] teacher planning a [MINUTES]-minute lesson on [TOPIC], aligned to [SUPPLIED STANDARD TEXT]. Write the full plan with these sections and nothing else: 1. Learning objective, in student-facing "I can" language 2. Warm-up (3-5 min) that surfaces prior knowledge 3. Mini-lesson with the exact steps I model, in order 4. Guided practice, including what I circulate and look for 5. Independent practice 6. Exit ticket — one question that would actually reveal who did not get it 7. The single most common misconception on this topic, and the exact question I ask to catch it Keep every section short enough to read at a glance while teaching. No introduction, no summary. Use only supplied facts and fictional examples. Do not infer identity, pronouns, achievements or diagnoses. If key evidence is missing, ask instead of inventing it. Review all results before classroom use.

13. One task, three levels

All grades

Three entry points into the same lesson, with a shared learning objective.

The prompt

Take the task below for [GRADE] [SUBJECT] and give me three versions: - Scaffolded: same thinking, more support (sentence starters, worked example, chunked steps) - On-level: as written, tightened if needed - Extension: same topic, genuinely harder thinking — not just more questions All three must be able to run in the same room at the same time, and end with students able to share in one discussion. TASK: [PASTE YOUR TASK] Use only supplied facts and fictional examples. Do not infer identity, pronouns, achievements or diagnoses. If key evidence is missing, ask instead of inventing it. Review all results before classroom use.

Fictional example input

Create three versions of this Grade 4 math task: compare 1/2 and 3/4 and explain which is larger. Keep the same fraction-comparison objective. Include a shared discussion question and an answer key.

Illustrative draft - not a recorded API execution

Supported task

Draw two equal-sized rectangles. Split each into four equal parts. Shade two parts in the first and three in the second. Complete: 1/2 = __/4. Therefore __ is larger because __.

Independent task

Compare 1/2 and 3/4. Draw a model or use equivalent fractions to explain your answer in two sentences.

Extension task

Find a fraction strictly between 1/2 and 3/4. Show why it belongs between them using equivalent fractions.

Shared discussion

Why must the wholes be the same size when we compare?

Answer key

1/2 = 2/4, so 3/4 is larger. One extension answer is 5/8 because 1/2 = 4/8 and 3/4 = 6/8. Check equal-sized wholes and equal partitions.
