# A toolkit, not an autopilot

This edition contains 300 focused prompts and 12 step-by-step workflows. Sixty selected
prompts include distinct editorial output excerpts. The remaining prompts include
deliberately incomplete input-check exercises: a good assistant should ask what is missing,
not invent a polished answer. These are not 300 logged model tests or measured classroom outcomes.

## Your first ten minutes

1. Choose one task you actually need this week. Start with LP-001, WA-001 or PC-001.
2. Open the companion HTML and copy the prompt. The PDF also has selectable text; it does not rely on unreliable PDF clipboard buttons.
3. Fill each required input with verified information. For learner-related tasks use fictional or permitted non-identifying information only.
4. Ask for one draft. Correct missing facts before requesting extra outputs.
5. Verify the content independently and adapt the voice to your classroom. Save only the approved artifact in your normal system.

## Why some tools look related

Related tools can serve different stages. LP-033 places an exit ticket in instruction;
AS-015 interprets its evidence. LP-051 plans project sequencing; WA-037 communicates
milestones to learners. DF-032 organizes temporary support; CM-024 explains regrouping
without stigma. Workflows link these stages rather than adding 12 unrelated prompt banks.

Repeated safety rules are intentional: a copied prompt should retain essential boundaries.
Select the smallest useful tool instead of running every variation. Examples are compact
excerpts, not every output field promised by the corresponding full prompt.

## Scope and fit

The core examples lean toward grades 3-8 and can be adapted carefully for other grades.
This is not a complete K-2 literacy curriculum, a special-education program, a validated
assessment system or a replacement for subject expertise. The extension guide covers
additional teacher situations without pretending a short prompt replaces specialist work.
