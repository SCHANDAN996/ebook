# RC-011 | Write a strength statement tied to a specific learning objective

## Use this when

Choose this focused tool when your immediate task is to write a strength statement tied to a specific learning objective. Use the task-specific check below to distinguish it from related tools.

## Teacher inputs

- [GRADE_SUBJECT: exact age/grade and subject]
- [GOAL: the learning or communication purpose]
- [OBJECTIVE: supply verified information; do not leave blank]
- [OBSERVED_SUCCESS: supply verified information; do not leave blank]
- [CONSTRAINTS: duration, format, resources and approved access requirements; write none only if confirmed]

```text
Write a strength statement tied to a specific learning objective.
```
