# RC-002 | Turn evidence into a balanced report comment

## Use this when

You have assessment evidence and need a concise, defensible comment. Use the task-specific check below to distinguish it from related tools.

## Teacher inputs

- [GRADE_SUBJECT: exact age/grade and subject]
- [GOAL: the learning or communication purpose]
- [ONE_RECORD: supply verified information; do not leave blank]
- [LEARNING_EVIDENCE: supply verified information; do not leave blank]
- [LENGTH: supply verified information; do not leave blank]
- [CONSTRAINTS: duration, format, resources and approved access requirements; write none only if confirmed]

## Copy-paste prompt

```text
Turn evidence into a balanced report comment.

Required inputs:
- [GRADE_SUBJECT: exact age/grade and subject]
- [GOAL: the learning or communication purpose]
- [ONE_RECORD: supply verified information; do not leave blank]
- [LEARNING_EVIDENCE: supply verified information; do not leave blank]
- [LENGTH: supply verified information; do not leave blank]
- [CONSTRAINTS: duration, format, resources and approved access requirements; write none only if confirmed]

Specific requirements:
Draft one balanced comment and map each factual clause to that record. Do not manufacture a strength to satisfy a formula.

Output:
Return the named artifact with all questions, directions, examples or text needed for the task; put teacher keys and notes separately from student/family-facing text.

```

## Fictional test case

Fictional evidence: eight of ten one/two-step equation items correct; work shows inverse operations; two errors involve negative numbers; 65 words.

## Sample output

**Editorial illustration - selected excerpt, not a logged AI run or classroom result.**

[LEARNER] solved eight of ten one- and two-step equation items correctly and showed inverse operations in the working. A next step is to check calculations involving negative numbers by substituting the answer into the original equation. Evidence trace: accuracy count and inverse-operation statement both come from the supplied record. No claim about effort or future improvement is added.
