# RC-001 | Build an evidence-safe comment bank

## Use this when

Choose this focused tool when your immediate task is to build an evidence-safe comment bank. Use the task-specific check below to distinguish it from related tools.

## Teacher inputs

- [GRADE_SUBJECT: exact age/grade and subject]
- [GOAL: the learning or communication purpose]
- [APPROVED_CRITERIA: supply verified information; do not leave blank]
- [BANK_SIZE: supply verified information; do not leave blank]
- [CONSTRAINTS: duration, format, resources and approved access requirements; write none only if confirmed]

## Copy-paste prompt

```text
Build an evidence-safe comment bank.

Required inputs:
- [GRADE_SUBJECT: exact age/grade and subject]
- [GOAL: the learning or communication purpose]
- [APPROVED_CRITERIA: supply verified information; do not leave blank]
- [BANK_SIZE: supply verified information; do not leave blank]
- [CONSTRAINTS: duration, format, resources and approved access requirements; write none only if confirmed]

Specific requirements:
Create evidence-required comment frames with next-step slots. Mark every invented illustration as fictional and never prefill real learner claims.

Output:
Return the named artifact with all questions, directions, examples or text needed for the task; put teacher keys and notes separately from student/family-facing text.

```

## Fictional test case

Fictional mathematics comment-bank request; two templates; evidence and learner details intentionally absent.

## Sample output

**Editorial illustration - selected excerpt, not a logged AI run or classroom result.**

Template A: [LEARNER] demonstrates [SPECIFIC_SKILL], as shown by [VERIFIED_EVIDENCE]. A next step is [ACTION]. Template B: In [TASK_WINDOW], [LEARNER] showed [OBSERVED_PROGRESS]. Continued practice with [TARGET] will be supported through [PLANNED_STRATEGY]. These are selection frames, not ready-to-send comments. Keep evidence slots unresolved until supported; do not insert generic praise to make a template sound complete.

## Teacher verification checklist

- [ ] Task-specific acceptance: Create evidence-required comment frames with next-step slots. Mark every invented illustration as fictional and never prefill real learner claims.
- [ ] Factual claims trace to supplied evidence; proposals and unknowns are labelled.
- [ ] Answers and subject content checked independently; access and local policy preserved.
- [ ] No identifying or sensitive records were shared; final recipient/content checked locally.
