# WF-007 | Project launch pack

## Outcome

Turn a learning goal into a clear project brief, milestone plan and assessment pack.

## Teacher inputs

Supply the source goal, verified constraints and only non-identifying evidence needed for the next stage. This workflow's specific input requirements are listed in its numbered stages. Do not paste a cumulative student dossier.

## Workflow

1. Define the objective, final evidence, duration, resources, audience and privacy boundaries.
2. Create the driving question, authentic scenario, final-product requirements and student choice limits.
3. Build milestones, mini-deadlines, teacher checkpoints and a recovery path for missed work.
4. Create the rubric, individual-accountability evidence and peer-feedback protocol.
5. Audit workload, group equity, accessibility, copyright and public-sharing risk; assemble the launch pack.

Pass only the necessary previous **reviewed** output, not the entire conversation. Keep a local version label for each approved artifact. If an upstream fact changes, recheck every dependent artifact. Reset context between learner records.

## Fictional end-to-end example

Editorial worked illustration, not a recorded AI run or classroom test.

Inputs: Grade 6; three-lesson fictional water-use proposal; supplied invented data: tap A 2 units, tap B 5 units per equal interval.

1. Driving question: which tap should the fictional site investigate first?
2. Product: evidence-based recommendation with a limitation.
3. Milestones: interpret supplied data; draft proposal; revise after feedback.
4. Individual evidence: explain why equal observation intervals matter.
5. Audit: values are fictional practice data, not measured school results; audience stays in class.
