# WF-006 | Emergency substitute pack

## Outcome

Create a self-contained, safe lesson pack another adult can run without guessing.

## Teacher inputs

Supply the source goal, verified constraints and only non-identifying evidence needed for the next stage. This workflow's specific input requirements are listed in its numbered stages. Do not paste a cumulative student dossier.

## Workflow

1. List the schedule, subject, learner routines, materials already available, prohibited activities and policy placeholders.
2. Choose a realistic objective and create a no-technology core lesson with exact read-aloud directions.
3. Add student task pages, answer guide, early-finisher option and collection instructions.
4. Create contingencies for missing materials, shortened time and learners needing established supports.
5. Audit safety, supervision, timing and unknown procedures; assemble the one-page overview and attachments.

Pass only the necessary previous **reviewed** output, not the entire conversation. Keep a local version label for each approved artifact. If an upstream fact changes, recheck every dependent artifact. Reset context between learner records.

## Fictional end-to-end example

Editorial worked illustration, not a recorded AI run or classroom test.

Inputs: Grade 4; 40-minute map lesson; board grid and paper; emergency routines not supplied.

1. Draft a 3x3 grid with north upward; place a library A1 and pond C1.
2. Model coordinates, then ask the direction from library to pond: east.
3. Independent product: learner draws and labels a different map with a key.
4. Backup: draw the map on the board if atlases are unavailable.
5. Hold operational use until the teacher attaches local attendance, supervision and emergency instructions.
