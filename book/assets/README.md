# Asset register

Planned assets: one cover image, ten chapter-divider illustrations, a small icon set
and only the diagrams that materially improve understanding. Avoid decorative stock
photos on prompt pages.

Every final asset needs a record containing its filename, creator/source, creation
date, licence or generation note, permitted use and alt text. Generated images must
not contain embedded headings or prompt text. Typography is added during layout.

The initial direction is a calm editorial classroom style using navy, teal, coral and
warm paper tones. This direction remains provisional until sample spreads are approved.
