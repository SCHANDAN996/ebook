# Review records

Review records are separate from prompt files so an edit cannot accidentally preserve
an old approval. Each approval must bind to a content fingerprint and identify:

- prompt or workflow ID;
- content version and SHA-256 fingerprint;
- reviewer role, not private personal details;
- subject/grade scope;
- checks performed;
- decision and date;
- unresolved limitations.

AI comparison scores are editorial evidence, not human approval. No real student data
belongs in reviews, examples or screenshots committed to this public repository.
