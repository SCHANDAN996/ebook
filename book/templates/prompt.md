# Replace with a clear outcome

## Use this when

Explain the real teacher task in one sentence.

## Teacher inputs

- `[INPUT]`: Say exactly what belongs here.

## Copy-paste prompt

```text
Write the complete prompt here. Keep every missing fact as a visible [PLACEHOLDER].
Require an exact output structure and a final self-check. Do not ask for identifiable
student information.
```

## Fictional test case

Provide a complete fictional or non-identifying filled prompt. Never use initials as
anonymization and never imply that a fictional test was a real classroom result.

## Sample output

Use `Not included in this edition.` unless this is one of the 60 selected examples.

## Teacher verification checklist

- [ ] All supplied facts are preserved; no facts were invented.
- [ ] Subject content and any answer key are correct.
- [ ] Difficulty, materials and timing fit the named classroom.
- [ ] Names, dates, standards and availability remain placeholders unless supplied.
- [ ] The result follows school policy and is reviewed before use.

## Editorial notes

Record known limitations, model-test findings and the reason for any unusual wording.
